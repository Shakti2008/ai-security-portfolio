## GitHub Pages setup

Open **Settings → Pages**. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.

## Course evidence checklist

- Verify the deployed site on desktop and mobile.
- Test the menu, links, and keyboard navigation.
- Ask a classmate to perform a specific task and record the actual result.
- Open a GitHub issue for feedback and respond to it.
- Make a meaningful revision, link the commit, and have the reviewer retry.
- Update the documentation with verified outcomes.

The full personal career reflection belongs in private Canvas, not this public repository.
